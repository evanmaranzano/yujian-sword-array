## 一、已明确的业务目标与约束

### 1.1 体验目标（任务书明确）
- 观众**无任何穿戴设备**，以**空手挥手手势**实时驱动大屏内的御剑/飞剑 3D 特效交互。
- 交互路线被限定为：**纯视觉空中手势**（排除手持控制器、穿戴设备、标记点等一切附加物）。
- 强调**实时**：手势与画面反馈之间无明显延迟（"实时驱动"）。

### 1.2 受众与运营模式（任务书明确）
- 面向**公共展厅访客**：非专业用户、首次接触即上手、年龄与身高跨度大。
- **多人轮流体验**（同一时刻单人/单组体验，非多人同时并行交互）。
- **7×24 小时无人值守运行**：现场无操作员、无讲解员。

### 1.3 输出载体（任务书明确）
- **展厅实体大屏幕实时渲染输出**。
- 明确排除：短视频后期合成、AR 手机特效。

### 1.4 由上述目标推导的隐含约束（任务书未直说但逻辑上必然成立）
- 现场必须部署**视觉传感器**（单目/双目/深度相机中的一种或多种），且其安装位置、视场、供电、走线属于现场条件的一部分。
- 现场必须有**本地实时算力**（图形工作站或边缘计算主机）承担"视觉推理 + 3D 实时渲染"双重负载；输出到实体大屏意味着需要独立的显示输出链路。
- 无人值守 ⇒ 系统必须具备**自动开关机、异常自动恢复、看门狗**等能力；交互引导必须**自解释**（观众无需培训即可开始）。
- 轮流体验 ⇒ 需要**体验状态管理**（开始→体验→结束→重置/吸引下一位），这是内容逻辑的一部分。

## 三、本类大屏手势交互项目通用前置风险点（仅陈列，不含对策）

1. **环境光干扰**：逆光、顶光射灯、LED 屏自发光导致相机过曝或人脸/手部过暗。
2. **屏幕反射入镜**：大屏画面或观众倒影被相机捕获，形成反馈回路或误识别。
3. **光照条件漂移**：开馆/闭馆、季节变化、天气变化导致现场光照与调试时不一致。
4. **相机拍屏摩尔纹/频闪**：相机拍到 LED 屏产生摩尔纹、滚动条带，污染输入画面。
5. **复杂背景与误触发**：路过观众、参观者围观、工作人员走动被识别为有效交互。
6. **多人入画的身份混淆**：轮流交接时前一位未退出、后一位已进入，状态串扰。
7. **人体尺度差异**：儿童骨架比例与成人差异大，同一识别模型对不同身高稳定性不一。
8. **遮挡问题**：观众相互遮挡、低身高观众被前方区域/设备遮挡。
9. **距离与视场的矛盾**：近距离大屏需要广角，广角带来边缘畸变与深度估计误差。
10. **传感器安装风险**：正装/倒装视角、线缆外露、设备被触碰移位、散热不良。
11. **算力瓶颈**：高分辨率实时渲染 + 视觉推理双负载，帧率与识别精度互相挤压。
12. **端到端延迟**：采集→推理→渲染→显示链路延迟累积，破坏"御剑"操控手感。
13. **长时间运行稳定性**：内存泄漏、显存碎片、驱动崩溃、相机掉帧/掉线。
14. **无人值守恢复**：异常退出后无人重启、断电后来电不自启、系统盘损坏。
15. **观众行为不可预期**：快速挥臂、跳跃、靠近镜头、遮挡镜头等非常规操作。
16. **安全风险**：观众挥臂碰到设备或他人、地面线缆绊倒、设备高空坠落。
17. **界面划分风险**：装修、弱电、硬件、内容、集成多方责任边界不清导致返工。
18. **验收标准模糊**："体验流畅""识别准确"无量化指标，验收阶段争议。
19. **现场调试窗口短**：开展前可用于现场联调的时间有限，问题暴露不充分。
20. **内容合规**：展厅内容审核（题材、画面、音效）的不可预期修改。
21. **供应链风险**：相机/显卡等关键硬件到货周期长或停产缺货。
22. **运维交接断层**：交付后运维方未参与开发，故障定位困难。
